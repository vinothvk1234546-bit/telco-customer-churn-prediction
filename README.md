# Telco-Customer-Churn-Prediction
End-to-end machine learning project to predict telecom customer churn using EDA, feature engineering, and Logistic Regression. Includes model evaluation and business insights.
🔹 Project Title

Telco Customer Churn Prediction

🔹 Problem Statement

Predict whether a telecom customer will churn.

🔹 Dataset Information

7000+ customers

Demographics

Services subscribed

Billing details

🔹 Exploratory Data Analysis

Include:

Churn distribution insight

Contract type impact

Monthly charges pattern

Correlation findings

🔹 Model Used

Logistic Regression

Accuracy Score

Confusion Matrix

🔹 Key Insights

Example:

Month-to-month contract customers churn more.

Higher monthly charges increase churn probability.

🔹 Technologies Used

Python

Pandas

Seaborn

Scikit-learn
